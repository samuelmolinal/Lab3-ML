**Curso:** ISIS2611 - Aprendizaje de Máquina
**Caso:** Ruta Alpes

## Integrantes

## Descripción

Se construyen modelos de clasificación (regresión logística, árboles de decisión y Random Forest) para anticipar si un conductor aceptará un cupón de Cafetería o de Restaurante(<20) en la aplicación Ruta Alpes. Se evalúa el efecto del desbalance de clases y de una técnica de balanceo, se identifican las variables más relevantes y se analizan los riesgos de sesgo al personalizar ofertas con datos demográficos.
